# The Museum of "Imperfect" Creativity

不完美创作博物馆 —— 一件以「人机共创中的不完美性」为主题的交互式线上展馆。
纯静态站点：HTML5 + CSS3 + 原生 ES6，**零依赖、零构建**。

## 在线访问

- 主站（含转场音效）：`./`
- 静音版：`./no-voice/`

## 本地运行

直接双击 `index.html` 即可；或起一个本地服务器（推荐，`file://` 下部分浏览器会限制媒体播放）：

```bash
python -m http.server 8000
# 然后打开 http://127.0.0.1:8000/
```

## 结构

| 文件 | 说明 |
|---|---|
| `index.html` | 结构骨架：两个页面级容器、两个模态弹窗与转场视频节点 |
| `style.css` | 全部样式：主题变量、版面布局、交互状态与响应式断点 |
| `script.js` | 全部逻辑：3D 舞台景深与视差、指针交互、画布绘制与弹窗状态机 |
| `particles.js` | 展厅氛围粒子：光斑 / 浮尘 / 星芒 / 换场爆发 |
| `shard-data.js` | Base64 内联的陶片底图（规避 `file://` 下的画布跨域污染） |
| `image/` | 作品图像与图标素材 |
| `transition.mp4` | 展厅 → 工作室的转场动画 |
| `技术说明文档.html` / `Technical-Documentation.html` | 技术说明（中 / 英） |

## 设计要点

- **立体纵深**：`.stage` 给 `perspective`，每件作品由四张景深不同的平面叠成，放大倍率全部交给浏览器的透视除法。纵深靠**硬边分层 + 投影 + 遮挡 + 视差**，不用模糊。
- **换场**：一张撕纸横掠过去盖住交接，纸背后完成换件。
- **配色**：靛蓝水彩纸 + 胡桃木 + 米纸。背景用 `background-blend-mode: luminosity` 只换色相、不动纹理。
