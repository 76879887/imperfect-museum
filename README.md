# The Museum of "Imperfect" Creativity

不完美创作博物馆 —— 一件以「人机共创中的不完美性」为主题的交互式线上展馆。
纯静态站点：HTML5 + CSS3 + 原生 ES6，**零依赖、零构建**。

## 在线访问

- 主站（含转场音效）：`./`
- 静音版：`./no-voice/`

## 本地运行

直接双击 `index.html` 即可；或起一个本地服务器（推荐，`file://` 下部分浏览器会限制媒体播放）：

```bash
python -m http.server 8000
# 然后打开 http://127.0.0.1:8000/
```

## 结构

| 文件 | 说明 |
|---|---|
| `index.html` | 结构骨架：两个页面级容器、两个模态弹窗与转场视频节点 |
| `style.css` | 全部样式：主题变量、版面布局、交互状态与响应式断点 |
| `script.js` | 全部逻辑：弧形展墙定位、指针拖拽、画布绘制与弹窗状态机 |
| `shard-data.js` | Base64 内联的陶片底图（规避 `file://` 下的画布跨域污染） |
| `image/` | 作品图像与图标素材 |
| `transition.mp4` | 展厅 → 工作室的转场动画 |
| `技术说明文档.html` | 技术说明（中文） |

## 设计要点

- **弧形展墙**：9 件作品沿一条半径 1100px 的凹面弧排开，越靠近画面中心放大越多（最大 1.5 倍），
  两侧随角度外扩让位，超出约 77° 的展品直接隐藏。位置每帧由 JS 写入 `transform`，
  所以 CSS 动画只用 `opacity` / `translate` / `scale` 这类独立属性，避免与行内样式打架。
- **分组陈列**：每 3 件一组（APPLE / CLOUD / BACK VIEW OF A PERSON），组名作为章节标题浮在组上方，
  组间用分隔线断开。
- **指针交互**：可按住拖拽展墙，松手后吸附到最近一件；底部波浪进度条上的小手可拖动擦洗进度。
- **画布工作室**：展厅点进度条图标进入，用 `shard-data.js` 内联的底图避开 `file://` 的跨域污染，
  支持画笔 / 橡皮 / 上传参考图，提交后与 AI 生成图并置对比。
